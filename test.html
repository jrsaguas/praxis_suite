Test Gemini desde celular

Este archivo sirve para verificar si tu API key funciona desde el navegador del celular.

No pongas la key dentro del código subido a GitHub. Pégala solo en este campo.
Listo. Pega la key y pulsa “Probar header”.

  
Si ves Funcionó, tu key sirve desde GitHub Pages/celular.
Si ves 401, la key está mal o no permitida.
Si ves 403, revisa restricciones/cuota/proyecto.
Si ves 404, cambia de modelo.
Si ves Failed to fetch, estás abriendo mal la URL o hay bloqueo de red/CORS.
